STORYCRAFT INDIA — CREATOR PORTFOLIO WEBSITE
================================================

Files:
- index.html: website content and sections
- styles.css: responsive design and blush-pink / navy / gold theme
- assets/storycraft-cover.jpg: supplied StoryCraft India cover artwork

Preview locally:
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. For the best local development experience, use VS Code with the Live Server extension.

Before publishing:
- Replace the three work-showcase placeholders with real public Reel/video links and accurate descriptions.
- Verify the audience metrics are current.
- Test email and Instagram links.
- Do not claim paid brand partnerships unless they have actually happened.

Publishing:
This package is a website source bundle, not a live hosted URL. You can publish it using GitHub Pages, Netlify, or another static website host. The site uses Google Fonts, so an internet connection is needed for those fonts; system fallbacks are included.
